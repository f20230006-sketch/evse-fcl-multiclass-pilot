# Matched global teacher control

This is a transparent post-evaluation baseline addition to the teacher-alignment study. It does not change, retune, or rerun the RBR global-aligned candidate or any other completed result. It tests class-balanced population with the same global prior-class teacher, same temperature2 type-level distillation, MLP, current/replay loss and merged calibration criterion. The purpose is to avoid crediting a teacher correction to RBR memory allocation.

Use precisely the existing split64, delayed rare-first schedule, memory60/client and300 pooled, calibration initialization seeds300/301/302, and evaluation seeds310-319. Fixed candidate grid: replay fraction0.25/0.50 and distillation weight0.1/1.0, learning rate0.003. Average mean-phase merged calibration recall over all three seeds and tie-break by first grid item. All24 calibration fits precede20 evaluations. Preserve all outcomes; comparisons are exploratory, post-evaluation-added controls with unadjusted paired t9 intervals. Do not call them preregistered confirmation. Do not select another RBR configuration based on this control's evaluation. Previous paper, studies, corrected RBR settings and models remain unchanged.
