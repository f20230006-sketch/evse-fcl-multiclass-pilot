# Datasets

- [CICEVSE2024, Canadian Institute for Cybersecurity](https://www.unb.ca/cic/datasets/evse-dataset-2024.html): use the network-traffic CSV collection, retaining its EVSE-A/EVSE-B directory layout. The research workspace located these under data/official/network_traffic; check the dataset path in the immutable experiment configuration before running. The sampler caps each attack type at 3,000 where available, preserves benign rows and records source file/row provenance.
- [Federated OCPP 1.6 Intrusion Detection Dataset, Dalamagkas et al.](https://zenodo.org/records/14887131): the reported check uses the publisher's balanced TCP/IP subset; the original runner expects data/external_validation_2026_11_12/Balanced_OCPP16_TCP-IP_Layer. It removes endpoint identifiers, ports, timestamps and provenance from model inputs and groups canonical bidirectional tuples connected by duplicate feature vectors. This is a distinct published corpus, not a verified capture-independent or site-independent replication.

Obtain both directly from their publishers under the applicable terms. No dataset, per-example source vector, or new checkpoint is supplied in this overlay. Source-file sharing and duplicate sensitivity are disclosed in the protocol. In the original evaluation, benign support is 16 rows and ICMP fragmentation support is five; these do not support a strong operational claim.
